# 🧘 MindSpace

**Приложение для самостоятельной психологической поддержки: дневник настроения, медитации, дыхательные практики и AI-ассистент.**

> ⚠️ MindSpace **не является медицинским изделием**, не ставит диагнозов и не заменяет консультацию врача или психолога. Если вам тяжело, обратитесь к специалисту. В экстренной ситуации звоните **112**.

> Статус: 📝 проектирование (рабочее название; требуется проверка доступности товарного знака).

---

## О проекте

MindSpace помогает взрослым пользователям справляться с повседневным стрессом, тревожностью и нестабильным настроением, а также формировать привычку регулярного самонаблюдения.

Система реализуется как мобильные приложения (iOS, Android) и веб-версия с единым серверным контуром.

**Цели:**
- сформировать у пользователей привычку регулярного самонаблюдения;
- повысить доступность базовых практик саморегуляции;
- обеспечить безопасную среду с механизмами реагирования на кризисные состояния.

**Целевая аудитория:** взрослые (18+), испытывающие повседневный стресс, нестабильность настроения, проблемы со сном и концентрацией, а также интересующиеся практиками осознанности.

## Функциональность (MVP)

| Блок | Описание |
|------|----------|
| **A. Аккаунт и онбординг** | Регистрация и вход (e-mail, телефон, Госуслуги / VK ID / Apple ID / Google), подтверждение возраста 18+, согласие на обработку персональных данных, стартовый опрос целей, экспорт и удаление данных, опциональный PIN / биометрия |
| **B. Трекер настроения и дневник** | Шкала настроения (5 или 7 уровней), эмоции и факторы, текстовые записи с шаблонами, графики по неделе / месяцу / году, корреляции, напоминания, экспорт в PDF/CSV, офлайн-режим с синхронизацией |
| **C. Медитации и дыхательные практики** | Каталог аудиопрактик с фильтрами, дыхательные упражнения с анимацией ритма, таймер, фоновое воспроизведение, история и серии (streaks), персональные рекомендации |
| **D. AI-ассистент** | Текстовый диалог с использованием техник из доказательных подходов (упражнения КПТ, заземление, рефрейминг), учёт данных трекера (с согласия), рекомендации практик, кризисный протокол |
| **E. Админ-панель (веб)** | Управление контентом, ролями сотрудников, модерация жалоб на ответы ассистента, агрегированная аналитика (DAU/MAU, удержание) без идентификации пользователей |
| **F. Уведомления и монетизация** | Push и e-mail уведомления, подписочная модель (бесплатный уровень + премиум) |

### 🛡️ Безопасность AI-ассистента

- Ассистент **не ставит диагнозов**, не назначает и не отменяет лечение, не рекомендует лекарственные препараты и дозировки.
- **Кризисный протокол:** при признаках суицидального риска, самоповреждения или насилия ассистент прекращает обычный сценарий, выражает поддержку и выводит актуальные контакты экстренных служб и служб психологической помощи РФ (в т. ч. 112). Контакты помощи доступны без обращения к серверу (встроены в клиент).
- Детектирование реализуется комбинацией классификатора и правил; срабатывания протоколируются в обезличенном виде.
- Постоянная пометка в интерфейсе: «Вы общаетесь с ИИ, а не с человеком».
- Регулярный red teaming на наборах кризисных, манипулятивных и пограничных сценариев.

## Нефункциональные требования (кратко)

- **Доступность:** серверная часть ≥ 99,5 % в месяц; ежедневное резервное копирование (хранение ≥ 30 суток), RPO ≤ 24 ч, RTO ≤ 4 ч.
- **Производительность:** холодный старт ≤ 3 с, открытие экрана ≤ 1 с, первый токен ответа ассистента ≤ 3 с (в 95 % случаев).
- **Нагрузка (MVP):** до 50 000 зарегистрированных пользователей и 5 000 одновременных сессий.
- **UX:** соответствие WCAG 2.1 AA, светлая и тёмная темы, спокойная цветовая гамма, без геймификации с вызывающей тревогу механикой.
- **Платформы:** iOS 16+, Android 9+ (API 28+), актуальные Chrome / Safari / Firefox / Edge.

## Безопасность и защита данных

Данные о состоянии психического здоровья относятся к **специальным категориям персональных данных** (ст. 10 152-ФЗ).

- Размещение и обработка ПДн граждан РФ на территории Российской Федерации (ч. 5 ст. 18 152-ФЗ).
- Письменное согласие на обработку ПДн отдельным документом; возможность отзыва в любой момент.
- Шифрование: TLS 1.2+ при передаче, AES-256 при хранении; отдельное шифрование записей дневника и диалогов.
- Принцип минимизации данных, ролевая модель доступа, двухфакторная аутентификация сотрудников, журналирование доступа.
- Аналитика строится на обезличенных идентификаторах; передача содержания дневника и диалогов в сторонние системы аналитики и рекламы запрещена.
- Права субъекта: просмотр, исправление, выгрузка и удаление данных через интерфейс.
- Соответствие OWASP ASVS и OWASP MASVS, защита от инъекций, XSS, CSRF, rate limiting.
- Реклама сторонних товаров и услуг в интерфейсе в MVP не допускается.

## Технологический стек (рекомендуемый, уточняется на этапе проектирования)

| Слой | Технологии |
|------|-----------|
| Мобильные приложения | Flutter или React Native (либо нативные Swift / Kotlin) |
| Веб | React + TypeScript |
| Бэкенд | Python (FastAPI) или Node.js (NestJS) |
| База данных | PostgreSQL |
| Кэш и очереди | Redis |
| Хранилище медиа | S3-совместимое + CDN для аудио и видео |
| Инфраструктура | Docker, Kubernetes (или эквивалент); окружения dev / test / stage / prod; размещение в РФ |
| API | REST (OpenAPI 3.0), WebSocket / SSE для потоковой выдачи ответов ассистента |
| Интеграции | APNs / FCM (или российские альтернативы), e-mail/SMS-провайдер, платёжный шлюз, ЕСИА (Госуслуги) |

Опционально после MVP: интеграция с HealthKit и Health Connect (шаги, сон, пульс) — только с явного согласия пользователя.

## Этапы разработки

| № | Этап | Срок (ориентир) |
|---|------|-----------------|
| 1 | Аналитика и предпроектное исследование | 4 недели |
| 2 | Проектирование (архитектура, UX, дизайн-система, модель угроз) | 6 недель |
| 3 | Разработка (бэкенд, клиенты, админ-панель) | 14–16 недель |
| 4 | Подготовка контента (практики, тексты, справочники, верификация психологом) | параллельно с этапом 3 |
| 5 | Тестирование (функциональное, нагрузочное, безопасность, качество ассистента, закрытая бета) | 6 недель |
| 6 | Подготовка к запуску (уведомление Роскомнадзора, публикация в магазинах) | 3 недели |
| 7 | Внедрение и опытная эксплуатация | 4 недели |

Общий ориентир на MVP — 6–8 месяцев. Допускается итерационная методология (Scrum) внутри стадий.

## Целевые бизнес-показатели

Ожидаемые через 6 месяцев после запуска (целевые, не гарантированные):

- 30-дневное удержание ≥ 15 %;
- доля пользователей, сделавших хотя бы 3 записи настроения за неделю, ≥ 30 %;
- средняя оценка в магазинах приложений ≥ 4,5.

## Открытые вопросы

- Рабочее название «MindSpace»: нужна проверка доступности товарного знака.
- Не определены: состав способов входа, модель монетизации, выбор языковой модели и провайдера хостинга, наличие голосового ввода для ассистента.
- Требуется консультация юриста по вопросам регистрации как медицинского изделия, оформления согласий и трансграничной передачи данных.
- Необходимо привлечение клинического психолога-консультанта и порядок его участия в приёмке контента.
- Реквизиты сторон, сроки и бюджет заполняются Заказчиком (ориентир трудоёмкости MVP: ___ чел.-часов).
